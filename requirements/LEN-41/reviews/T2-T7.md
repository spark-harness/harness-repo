## Findings

### P1: Formal `spark-idl-java` version does not yet contain the Lendora applicant package

- Dimension: contract compatibility / consumer readiness
- File: `business-repo/services/backend/applicant-api/pom.xml`
- Issue: the committed dependency keeps `com.spark.contract:spark-idl-java` at `spark.contract.version=0.1.0`. Local verification shows that published/resolved `0.1.0` does not yet contain `com.vesta.lendora.applicant.v1`, so default `mvn -B test` cannot compile the migrated imports.
- Impact: `applicant-api` cannot be merge-ready until IDL release publishes a formal `spark-idl-java` version that includes the new Lendora applicant generated package, and the consumer points to that version.
- Required fix or decision: Publish the formal generated contract version from the LEN-41 IDL commit, update `spark.contract.version` if the formal version is not `0.1.0`, then rerun `applicant-api` default `mvn -B test`.
