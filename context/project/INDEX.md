# Project Context Index

项目级知识按项目、领域、服务逐层组织。

推荐结构：

```text
context/project/{project-name}/{domain-name}/{service-name}/
├── INDEX.md
├── sop/
└── experience/
```

## 使用原则

- 先通过 `.service-matrix/dependencies.yaml` 确认项目、模块和服务。
- 再读取对应 `INDEX.md`。
- 只沉淀业务语义、架构约束、SOP 和历史经验。
- 不复制业务代码实现。
